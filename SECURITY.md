# Security Policy

## Supported versions

Only the latest stable release receives security fixes. Check the [releases page](https://github.com/diegopn/bellbird/releases) for the current version; older versions may no longer be supported.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or discussions. GitHub private vulnerability reporting is not currently enabled for this repository. Until it is enabled, use the [contact page](https://diegopn.github.io/#contato) with **[Security] Bellbird** in the subject to request a private channel. Do not include technical details or attach proof-of-concept files in that initial message.

Include the affected Bellbird version, operating system, input format, steps to reproduce the issue, and its potential impact. Use a small, synthetic sample file when needed. Do not send personal or confidential documents, credentials, or other sensitive data.

Please give the maintainer a reasonable opportunity to investigate and prepare a fix before publicly disclosing the vulnerability. For non-security bugs, use the [issue tracker](https://github.com/diegopn/bellbird/issues). For conduct concerns, see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
